# コピー・見出しのスロップ診断

1. 本文、ブリーフや確認できる事実、掲載位置、前後の文面を読む。候補一覧は元の順序で読む。
2. 典型パターンを手がかりに、判定ルールに沿って読む。違和感があれば該当箇所と、読者に何が伝わりにくいかを示す。
3. 各案の採否を「使用可」「要修正」「文脈待ち」のいずれかで示す。

## 判定ルール

- **掲載位置。** 何のページか、何ができるかなど、その場で読者に必要な情報が伝わるか。隣に商品名や説明があれば省略できる。事実と約束の強さは資料で確かめる。
- **題材の具体性。** ブリーフから何を選んで伝えたか。題材を替えても通る表現や、よくある連想が、実際の使い方や違いを伝えているかを見る。
- **区切りや転換の働き。** 読点、短い二文、対比、問いかけなどが情報を整理したり、意味を進めたりしていれば使える。区切りの前後で内容が重複したり、勢いだけで話を大きく見せたりする箇所は指摘する。
- **候補の幅。** 候補の幅が求められる場合は、訴求点・使う場面・伝える情報が案ごとに変わるかを見る。

## 典型パターン

- 読点で前後に切る。短い二拍子や `〜、〜。`、句点なしの `〜、〜`。
- 短文を重ねる。`〜した。でも〜` のように途中で話を転じる形もある。
- 助詞で言いさす。例は `〜を。`、`〜へ。`。
- 対句や反復でそろえる。`〜も、〜も`、`〜から〜へ`、数量をそろえた対句など。
- 時間や条件で場面を切り替える。例は `〜したら、〜`、`〜する前に、〜`。
- 問いかけ、独り言、セリフで話を切り出す。
- 「あの〜」「もう一度」で余韻を出したり、題材を別のものに見立てたりする。
- ブリーフの要素をほぼそのまま並べ直す。長い案ほど説明文の言い換えに近づく。
- 題材からすぐ連想できる小道具や情景が、複数案に繰り返し出る。
- 候補一覧で短い案から長い案へ毎回同じ順に並ぶ。用途やトーンを変えても構成や文面が重複する。

## 判定例

### 要修正

- **紙の避難所マップの題名**

  > 停電避難マップ

  停電中も使える地図か、停電時の避難先を示す地図かが曖昧。

- **深夜バスの街頭ポスター**

  > 電車を降りたその先へ。深夜バス、試験運行スタート。

  終電後に駅から住宅街へ走ることが分からない。

  **対照例**

  > 終電後の駅に、住宅街へ向かうバスが走ります。

  時間帯と行き先を伝える。

- **吹奏楽団の紹介タイトル**

  > 最初の一音はかすれた。それでも私たちは吹奏楽団を名乗った

  最初の一音がかすれたという出来事はブリーフにない。楽器を手放した人たちが週末に演奏を再開するという題材の特徴も伝わらない。

- **廃番部品の再製作サービスのH1**

  > 作り終えたはずの部品に、もう一度、刃を入れる。

  元の部品に加工を加えるように読める。現物を採寸して新しい部品を作ることが伝わらない。

- **共同制作の法律相談ページのH1**

  > 描き出す前に。書き出す前に。ふたりで決めておこう。

  冒頭二文で同じ準備段階を繰り返す。著作権や報酬を相談できる窓口だと分からない。

### 使用可

- **桃ジャムの商品説明の見出し**

  > スプーンですくえば、大きな桃の果肉。

  すくう場面から果肉の大きさを想像させる。

- **対戦ゲームのステージ紹介の見出しコピー**

  > 大都会で！大自然で！

  見出しの別の文言と直下の説明でステージ紹介だと分かる。このコピーは舞台の幅を伝える役割に絞っている。

## 形式集計

[detect_slop.py](scripts/detect_slop.py) は句読点・候補順と文字数・重複を集計する。

- テキストは番号の振り直しで候補のまとまりを区切る。`■ 題材`、次の行のブリーフ、`【条件】` に対応する。
- JSONL は `copy` が必須。`id`、`field`、`placement`、`brief` は任意。`--brief` でブリーフの既定値を渡せる。
- `--json` の `items` は入力順。IDの既定値はファイル名と行番号。`tag_spans` は返却された `text` 上の文字位置で、0始まり・末尾を含まない。`clean_count` と `clean_rate` は句読点タグが0件の案の数と割合。
