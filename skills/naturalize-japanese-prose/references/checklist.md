# 自然な日本語へ書き直すためのチェックリスト

上から順に確認する。意味保存で不合格があれば、自然さの評価へ進まず改稿を戻す。

## 0. 三つの評価軸

- [ ] 日本語として自然であり、文脈に合わない定型表現や不自然なリズムがない。
- [ ] 読み返さなくても、主語と述語、修飾先、条件、因果、対比を解析できる。
- [ ] 想定読者が、文章中の定義と前提を使って中心となる内容を説明できる。

三つを別々に判定する。自然な文でも、一読で構造を取りにくい場合や、想定読者に必要な前提が欠けている場合は合格にしない。読者テストをしていない場合、実際の理解率を数値で判定しない。

## A. 意味と事実の保存

- [ ] 原文の主張、説明、例、反論、結論がすべて残っている。
- [ ] 原文にない事実、解釈、理由、効果、感情、評価を加えていない。
- [ ] 数値、単位、日付、名称、用語、列挙項目を変えていない。
- [ ] 肯定と否定、条件と結果、原因と相関、一般と例外を入れ替えていない。
- [ ] 「必ず」「おおむね」「可能性がある」など、主張の強さを変えていない。
- [ ] 誰の発言・判断・評価かを変えていない。
- [ ] 引用、出典、リンク、コード、数式の内容を変えていない。
- [ ] 重複を削った場合も、その命題が別の箇所に明示されている。
- [ ] 原文の曖昧さを推測で解消していない。

## B. 構成

- [ ] 導入は必要な前提か本題から始まり、題名の言い換えだけで終わっていない。
- [ ] 見出し、予告文、本文、まとめが同じ内容を繰り返していない。
- [ ] 各段落の中心が分かり、話題の切り替わりが自然である。
- [ ] 「第一に、第二に、第三に」や賛否の対称形を、内容以上に整えていない。
- [ ] 重要度に応じて説明量に差があり、すべての段落が同じ型になっていない。
- [ ] 結論は新しい一般論や励ましを足さず、本文から導ける地点で止まっている。

## C. 文と論理

- [ ] 主語と述語が対応し、離れすぎていない。
- [ ] 修飾語が何を修飾するか一読で分かる。
- [ ] 一文に原因、逆接、例外、評価を詰め込みすぎていない。
- [ ] 「場合は」と「すると」など、同じ結果に複数の条件をねじれた形で掛けていない。
- [ ] 一文内で利用者、画面、システムなどの主語が無理に交代していない。
- [ ] 重要な条件や注記を括弧内に押し込めていない。
- [ ] 「〜することができる」「〜を行う」などを必要以上に使っていない。
- [ ] 抽象名詞を重ねず、可能な箇所では動作を動詞で示している。
- [ ] 指示語の参照先が一つに定まる。
- [ ] 接続語が実際の論理関係と一致し、なくても明白な箇所に重ねていない。
- [ ] 「つまり」以降が直前の文を言い直すだけになっていない。
- [ ] 主体不明の「求められる」「考えられる」を不用意に増やしていない。
- [ ] 初出の概念を不要な否定から導入せず、まず肯定形で定義している。

## D. 声とリズム

- [ ] 敬体・常体、用語、表記が一貫している。
- [ ] 同じ語尾と同じ長さの文が機械的に続いていない。
- [ ] 「また」「さらに」「一方で」「しかし」が段落頭に反復していない。
- [ ] 「だけでなく」「ではなく」の対句を必要な箇所だけに使っている。
- [ ] 留保表現を重ねず、原文の確実性の差が読み取れる。
- [ ] 比喩は題材固有の像を伝え、定型的な余韻を作るだけになっていない。
- [ ] かぎ括弧、太字、感嘆符、ダッシュ、絵文字などの強調を重ねていない。
- [ ] 読者への問いかけ、励まし、行動喚起が用途に合っている。
- [ ] タイトルや見出しの読点は、列挙、誤読防止、引用、意図的な間のいずれかを担い、二部構成を演出するためだけに置かれていない。
- [ ] 音読相当で息継ぎの位置が自然で、つかえる箇所がない。

## E. ジャンルと媒体

- [ ] 想定読者が理解できる語彙と説明量になっている。
- [ ] 初出の用語や記号を、想定読者がすでに知る語で定義している。
- [ ] 比較では、比較する二つの対象、比較軸、違いを明示している。
- [ ] 理解に必要な前提、例、因果が原文にない場合、自然な言い換えで不足を隠していない。
- [ ] 学術文の留保、技術文の用語、業務文の期限など、ジャンルの機能を保っている。
- [ ] UIの画面名、ボタン名、機能名が実物と一致し、勝手に改名されていない。
- [ ] クリック、タップ、入力、選択、表示などの操作と挙動を正確に区別している。
- [ ] 同じ概念に同じ語を使い、不要な言い換えで名称を揺らしていない。
- [ ] 書き手の個性や意図的な反復を、AIらしさとして消していない。
- [ ] 見出し、箇条書き、改行、文字数が媒体と依頼条件に合っている。

## F. 最終照合

- [ ] 原文の各命題を改稿内で一つずつ指せる。
- [ ] 改稿の各命題を原文内で一つずつ指せる。
- [ ] 修正理由を「AIっぽいから」ではなく、重複、曖昧さ、係り受け、過剰表示など具体的に説明できる。
- [ ] 直さなくてよい表現を残している。

## 判定

- **合格**: AとFがすべて合格し、B〜Eに読解を妨げる問題がない。
- **要確認**: 意味は保たれているが、読者、媒体、専門表記などの前提が不明で判断が分かれる。
- **不合格**: AまたはFに一つでも不合格がある。自然に読めても採用しない。
