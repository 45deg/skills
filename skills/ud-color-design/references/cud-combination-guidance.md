# CUD Combination Guidance

Use this file for palette choice and audit checks.

## How To Use

- Prefer the candidate sets below when a user asks for a chart, map, route diagram, slide palette, or sign system.
- Match the medium: `screen` maps to RGB values, `print` maps to CMYK values, and paint/signage needs production proofing.
- Treat these as safer starting points, not guarantees. Size, background, line weight, lighting, ink, paper, and display calibration still matter.
- If a pair appears in `avoid-or-reinforce`, do not use it as the only distinction. Add labels, icons, patterns, boundaries, line styles, or change the palette.

## Implementation Notes

- For a requested categorical palette, first choose the smallest candidate set that covers the number of categories.
- For extra categories, prefer labels/facets before appending more hues.
- For print, verify the selected set in a proof PDF and avoid assuming a screen-good set remains equally good on paper.
- For screen UI, check contrast separately; distinguishable colors do not guarantee readable text.
- For a forced risky pair, add at least two redundant cues if the information is safety-critical or navigational.
