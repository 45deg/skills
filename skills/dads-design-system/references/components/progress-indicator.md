# Progress Indicator

Purpose: Show that work is in progress or has measurable completion.

Use when users need confirmation that a task is running or advancing.

Avoid when there is no meaningful progress signal.

Key rules:
- Keep the state concise.
- Avoid implying precision when progress is indeterminate.
- Pair with nearby task context.

Accessibility: Announce state changes without interrupting unnecessarily.
