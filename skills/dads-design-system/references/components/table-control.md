# Table Control

Purpose: Hold filters, sorters, and controls for a data table.

Use when the table needs view-management tools.

Avoid when the table itself already provides enough control.

Key rules:
- Keep controls close to the table.
- Make each action explicit.
- Keep current filter/sort state visible.

Accessibility: Labels and current state must be clear.

Related: `table`, `divider`. Status: Guidance is pending.
