# Horizontal Menu

Purpose: Provide persistent top-level navigation.

Use when desktop navigation should remain visible and compact.

Avoid when content belongs in a drawer, mega menu, or utility strip.

Key rules:
- Keep hierarchy shallow.
- Keep labels short.
- Make current state visible.

Accessibility: Keyboard navigation and state indication are essential.

Related: `hamburger-menu-button`, `mega-menu`, `mobile-menu`. Status: Guidance is pending.
