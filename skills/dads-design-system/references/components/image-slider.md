# Image Slider

Purpose: Present a gallery-style image switcher.

Use when multiple images need to be browsed one at a time.

Avoid when a single image or simple grid is enough.

Key rules:
- Treat as a narrow container-style carousel.
- Keep the experience focused on image review.
- Avoid unnecessary text-heavy slide content.

Accessibility: Inherit carousel keyboard and update behavior.

Related: `carousel`, `image`.
