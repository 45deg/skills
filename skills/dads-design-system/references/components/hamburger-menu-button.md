# Hamburger Menu Button

Purpose: Open compact or mobile navigation.

Use when screen space is too tight for direct navigation.

Avoid when primary navigation can stay visible.

Key rules:
- Keep the button meaning obvious.
- Pair it clearly with the menu it controls.
- Use visible text where space allows.

Accessibility: Provide a clear accessible name and state.

Related: `drawer`, `mobile-menu`, `header-container`.
