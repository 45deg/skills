# Image

Purpose: Embed an image as content.

Use when the actual visual matters to understanding the page.

Avoid decorative, atmospheric, or placeholder imagery when users need information.

Key rules:
- Provide meaningful alternative text when the image conveys information.
- Use captions where they help comprehension.
- Mark purely decorative images so they do not add noise.

Accessibility: Informative images need clear names; decorative images should be ignored by assistive technology.

Related: `card`, `carousel`. Status: Guidance is pending.
