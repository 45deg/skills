# Utility Link

Purpose: Show a compact set of high-value utility links.

Use when common tasks or policy pages need quick access from the header or footer.

Avoid when the links belong in primary navigation.

Key rules:
- Keep the list short.
- Keep labels consistent and scannable.
- Place where users expect utility controls.

Accessibility: Keep labels descriptive and target sizes comfortable.

Related: `language-selector`, `header-container`, `mobile-menu`.
