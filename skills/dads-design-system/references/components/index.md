# Components

Use one file per component slug. Start here to identify nearby alternatives, then open the specific component file.

Main groups:
- Forms: `button`, `input-text`, `textarea`, `checkbox`, `radio`, `select`, `combobox`, `date-picker`, `file-upload`, `search-box`.
- Navigation: `breadcrumb`, `header-container`, `horizontal-menu`, `hamburger-menu-button`, `mobile-menu`, `mega-menu`, `menu-list`, `menu-list-box`, `language-selector`, `utility-link`, `page-navigation`, `step-navigation`, `tab`.
- Content: `card`, `heading`, `list`, `description-list`, `blockquote`, `image`, `image-slider`, `divider`, `chip-label`, `chip-tag`, `resource-list`.
- Feedback and overlays: `accordion`, `disclosure`, `notification-banner`, `emergency-banner`, `dialog`, `drawer`, `carousel`, `progress-indicator`.
- Data: `table`, `table-control`.

Deprecated or legacy-use-only components include `bottom-navigation` and `scroll-top-button`. Several component files note pending or sparse guidance; treat those as caution markers.
