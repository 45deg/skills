# Date Picker

Purpose: Collect a date through text fields, with an optional calendar.

Use when users must enter a date and calendar browsing adds value.

Avoid when a known date is better entered directly or when native/select controls create awkward scrolling.

Key rules:
- Use year, month, and day text fields.
- Keep support text explicit.
- Do not rely on placeholders.
- Open the calendar only from a button.
- Reflect typed values in the calendar.
- Use relevant autocomplete tokens.

Accessibility: Do not disable fields or the calendar trigger. Follow robust calendar dialog keyboard behavior when a calendar is present.

Related: `input-text`, `file-upload`.
