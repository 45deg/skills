# List

Purpose: Present list items, including numbered content where the number itself is part of the text.

Use when items need enumeration or legal/order-sensitive numbering.

Avoid fake lists built with line breaks, punctuation, or counters that are not part of content.

Key rules:
- Use semantic list structure.
- Keep nesting structurally correct.
- Make depth visible through indentation and marker style.
- Keep ordinal text stable and copyable when the number matters.

Accessibility: List semantics must expose the grouping and nesting.

Related: `resource-list`, `description-list`, `heading`.
