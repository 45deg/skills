# Search Box

Purpose: Let users search by keyword.

Use when the primary need is finding content by text.

Avoid when browse navigation already solves the task better.

Key rules:
- Keep the search affordance obvious.
- Keep the interaction simple.
- Decide whether suggestions, submit button, and advanced search are needed.

Accessibility: Label the field clearly and keep behavior predictable.

Related: `combobox`, `notification-banner`. Status: Guidance is pending.
