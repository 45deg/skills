# Chip Tag

Purpose: Show tag-like metadata or short item tokens.

Use when items need compact labels or user-managed tags.

Avoid when the text is long or needs explanation.

Key rules:
- Keep labels brief.
- Make removal affordances obvious when tags can be removed.
- Keep states visually consistent.

Accessibility: Ensure clear focus, clear removal behavior, and strong contrast.

Related: `chip-label`. Status: Guidance is sparse.
