# Description List

Purpose: Present repeated term-and-explanation pairs.

Use when values need matching definitions or metadata pairs.

Avoid when headings, bullets, or a table would communicate the structure better.

Key rules:
- Keep each term semantically paired with its description.
- Do not use the pattern as a heading substitute.

Accessibility: Use definition-list semantics so relationships are exposed.

Related: `heading`, `table`. Status: Guidance is pending.
