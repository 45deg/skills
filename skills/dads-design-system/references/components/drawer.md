# Drawer

Purpose: Provide an edge-docked overlay container.

Use when navigation or a side panel needs to slide in from the screen edge.

Avoid when a non-modal or inline panel would be clearer.

Key rules:
- Use modal behavior.
- Cover or block the rest of the page.
- Include a close control.

Accessibility: Trap focus, prevent background access, and restore focus when closed.

Related: `mobile-menu`, `hamburger-menu-button`.
