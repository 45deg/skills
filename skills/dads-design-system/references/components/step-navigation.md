# Step Navigation

Purpose: Show progress through a multi-step process.

Use when a workflow needs visible stages.

Avoid when simple previous/next navigation is enough.

Key rules:
- Keep steps legible.
- Make the current step obvious.
- Do not overstate progress if steps can branch.

Accessibility: Current-state semantics and keyboard support matter if interactive.

Related: `page-navigation`, `progress-indicator`. Status: Guidance is pending.
