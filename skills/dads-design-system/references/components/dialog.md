# Dialog

Purpose: Interrupt the current flow for a focused decision, acknowledgement, or short task.

Use when the user must respond before continuing.

Avoid when inline content, a notification, or a non-modal panel would work.

Key rules:
- Keep actions few and clear.
- Make close or cancel behavior obvious.
- Keep the title and purpose explicit.

Accessibility: Manage modal focus, label the dialog, prevent background interaction, and return focus when closed.

Related: `drawer`, `menu-list-box`, `mobile-menu`. Status: Guidance is pending.
