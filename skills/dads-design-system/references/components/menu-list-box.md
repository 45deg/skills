# Menu List Box

Purpose: Open a bounded menu panel from a labeled opener.

Use when a click reveals a menu list.

Avoid when opener meaning or panel alignment is ambiguous.

Key rules:
- Align the panel to the opener's edge.
- Open on click.
- Keep the parent-child relationship visually clear.

Accessibility: The opener should behave like a proper control with predictable focus behavior.

Related: `menu-list`, `dialog`, `mega-menu`.
