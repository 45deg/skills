# Divider

Purpose: Create a visual break between groups.

Use when sections, lists, or control groups need clearer separation.

Avoid when the divider would be the only thing conveying structure.

Key rules:
- Use full-width dividers for stronger section breaks.
- Use inset dividers for within-group separation.
- Keep enough margin around the divider.

Accessibility: Treat as decorative separation, not semantic structure.

Related: `menu-list`, `table-control`.
