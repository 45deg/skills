# Breadcrumb

Purpose: Show the user's position in a site hierarchy.

Use when the page sits inside a meaningful hierarchy.

Avoid when the path is ambiguous or there is no hierarchy to show.

Key rules:
- Place between header and page title.
- Let breadcrumbs wrap on wider layouts.
- On compact layouts, choose wrapping or horizontal scrolling consistently.
- If using horizontal scrolling, consider a wrapped version elsewhere on the page.

Accessibility: Keep link text short, ordered, and descriptive.

Related: `header-container`, `heading`, `notification-banner`.
