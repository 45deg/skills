# Chip Label

Purpose: Show compact status, category, or classification text.

Use when annotating rows, cards, or items with short state information.

Avoid when the chip is the only place a critical meaning is explained.

Key rules:
- Keep text short.
- Keep styling consistent across similar states.
- Do not make color the sole signal.

Accessibility: Maintain contrast and include text for meaningful states.

Related: `chip-tag`. Status: Guidance is sparse.
