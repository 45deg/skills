# Language Selector

Purpose: Let users choose display language.

Use when the site supports multiple content languages.

Avoid hiding language choice inside a cluttered utility area.

Key rules:
- Keep the control label as `Language`.
- Show language names in their own language.
- Place in the header or mobile menu depending on viewport.

Accessibility: Keep the current language obvious and make the control keyboard friendly.

Related: `utility-link`, `header-container`, `mobile-menu`.
