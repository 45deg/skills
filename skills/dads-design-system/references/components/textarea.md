# Textarea

Purpose: Collect freeform multi-line input.

Use when the answer needs explanation or detail.

Avoid when multiple-choice, shorter input, or a split question would reduce burden.

Key rules:
- State length limits in the label or nearby text.
- Show a character counter for long fields.
- Keep support text specific.
- Do not use placeholders as instructions.

Accessibility: Avoid disabled/readonly unless unavoidable, do not depend on `maxlength`, do not use live regions for routine validation, and never block copy/paste.

Related: `input-text`, `radio`, `checkbox`.
