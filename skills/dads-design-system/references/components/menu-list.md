# Menu List

Purpose: Bundle a set of menu items.

Use for local menus, dropdown contents, mega menus, or mobile navigation bodies.

Avoid icon language that blurs navigation versus expansion.

Key rules:
- Use end icons consistently.
- Do not mix link cues and expand/collapse cues casually.
- Use dividers and section titles to separate groups.

Accessibility: Interaction meaning must be visible, not only encoded by icon direction.

Related: `menu-list-box`, `mega-menu`, `mobile-menu`.
