# Mobile Menu

Purpose: Offer touch-friendly site navigation in narrow viewports.

Use when desktop navigation collapses behind a drawer or similar pattern.

Avoid deep hierarchy or mixing incompatible navigation styles.

Key rules:
- Keep hierarchy to about two levels.
- Do not mix slide and accordion styles in the same system.
- Use distinct icons for direct links versus expandable items.
- Use dividers and optional section icons to clarify groups.

Accessibility: Pair with hamburger and drawer patterns and keep focus/state handling clear.

Related: `hamburger-menu-button`, `drawer`, `horizontal-menu`.
