# Notification Banner

Purpose: Show important alerts or announcements that may require an optional response.

Use when a message is important but not emergency-level.

Avoid routine, overly complex, or action-heavy content.

Key rules:
- Title and icon are required.
- Description is optional.
- Keep actions modest, especially on small screens.
- If the banner itself is linked, make the clickable area unambiguous.
- If dismissible, persist dismissal appropriately.

Accessibility: Keep borders and text contrast strong, clickable areas obvious, and mobile behavior simple.

Related: `emergency-banner`, `drawer`.
