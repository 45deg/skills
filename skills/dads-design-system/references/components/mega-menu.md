# Mega Menu

Purpose: Provide broad dropdown navigation with grouped content.

Use when a horizontal menu needs richer content than a simple item list.

Avoid when simpler navigation is enough.

Key rules:
- Align the panel with its trigger.
- Group menu content clearly.
- Keep the hierarchy understandable.

Accessibility: Keyboard and focus behavior must be robust.

Related: `horizontal-menu`, `menu-list`. Status: Guidance is pending.
