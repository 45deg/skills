# Select

Purpose: Choose one option from a finite list.

Use when the list is modest and a compact control makes sense.

Avoid when there are five or fewer options and radio buttons would be clearer.

Key rules:
- Prefer native or OS-style list behavior.
- Keep labels short and specific.
- Keep options understandable without extra context.

Accessibility: Label and support text should be explicit; error text belongs near the control.

Related: `radio`, `date-picker`.
