# Radio

Purpose: Choose exactly one option from a set.

Use when only one answer should be selected.

Avoid when multiple answers may be selected.

Key rules:
- Keep options mutually exclusive.
- If choice is optional, include a deliberate no-selection option instead of relying on deselection.
- Keep labels clear and comparable.

Accessibility: Keep the group labeled and support keyboard selection.

Related: `checkbox`, `select`.
