# Carousel

Purpose: Step through multiple slides in a compact sequence.

Use only when a featured topic, story, or grouped visual sequence truly needs rotation.

Avoid when content should be visible immediately, slide count is high, or autoplay would be required to make the pattern useful.

Key rules:
- Do not autoplay.
- Do not depend on drag interaction.
- Keep slide copy short.
- Keep slide count low; six is a practical ceiling.
- Container-type carousels need a heading.
- Provide clear step navigation and a way to view all slides when appropriate.

Accessibility: Support keyboard navigation, visible focus, and status updates without timing dependence.

Related: `image-slider`, `emergency-banner`.
