# Header Container

Purpose: Organize logo, utility controls, global navigation, search, language choice, and menu trigger.

Use when building a responsive site header with mixed utility items.

Avoid overloading the header with unrelated content.

Key rules:
- Choose a layout mode appropriate to viewport width.
- Group header items by role.
- Reserve hamburger navigation for narrower layouts.
- Keep utility items distinct from primary navigation.

Accessibility: Preserve logical reading order and comfortable hit areas.

Related: `utility-link`, `language-selector`, `search-box`, `hamburger-menu-button`, `horizontal-menu`.
