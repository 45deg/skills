# Blockquote

Purpose: Present quoted passages as distinct block content.

Use when reproducing a cited statement, testimony, or excerpt.

Avoid when the goal is only emphasis or a decorative callout.

Key rules:
- Keep the quoted text semantically separate from body prose.
- Preserve attribution when it is available.
- Do not use quote styling as a generic highlight pattern.

Accessibility: Use quote semantics so assistive technology can distinguish the passage from ordinary body text.

Status: Guidance is sparse.
