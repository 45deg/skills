# Card

Purpose: Package one subject into a bounded container.

Use when grouping media with text, presenting item summaries, or showing comparable objects in a list or grid.

Avoid when precise data comparison is the main task or when nested interactive children would conflict with a clickable card surface.

Key rules:
- Keep a clear border; do not rely on shadow alone.
- Keep image, main, and supporting areas structurally consistent.
- Do not let interactive regions overlap.
- If the entire card is clickable, avoid competing links or controls inside it.

Accessibility: Maintain readable boundaries and one unambiguous focus target per interactive surface.

Related: `table`, `blockquote`, `image`.
