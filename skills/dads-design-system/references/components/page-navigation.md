# Page Navigation

Purpose: Move between adjacent pages or chapters.

Use when content is paginated or sequential.

Avoid when users need broader browsing instead of next/previous movement.

Key rules:
- Keep labels unambiguous.
- Keep order readable.
- Do not substitute this for full site navigation.

Accessibility: Preserve clear focus and readable order.

Related: `step-navigation`, `progress-indicator`. Status: Guidance is pending.
