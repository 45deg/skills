# Heading

Purpose: Mark page and section titles.

Use when a page or section needs a clear topic.

Avoid when styling list items or repeated term-description pairs.

Key rules:
- `h1` represents the page's main subject.
- Deeper levels represent nested sections.
- Shoulder text and subtitle belong in a heading group, not as separate heading levels by default.

Accessibility: Do not skip heading levels. Align dynamic headings with the surrounding document structure.

Related: `list`, `description-list`.
