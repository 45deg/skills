# Combobox

Purpose: Combine text entry or selection with a richer choice surface.

Use when a plain select or input is too limited for the interaction.

Avoid when `radio`, `select`, or `input-text` already solves the task cleanly.

Key rules:
- Keep behavior predictable.
- Make the popup relationship obvious.
- Confirm implementation details before adopting.

Accessibility: Keyboard and screen-reader behavior need careful implementation.

Related: `search-box`, `select`, `input-text`. Status: Guidance is pending.
