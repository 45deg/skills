# Accordion

Purpose: Collapse repeated sections of the same type.

Use when FAQs, update logs, or similar grouped items need compact presentation.

Avoid when there is only one section, the hidden content is essential, or the goal is only to save space.

Key rules:
- The header should summarize the body.
- Body content may contain mixed content.
- Optional return links should point back to the header.
- Prefer native disclosure behavior when possible.

Accessibility: Custom implementations need keyboard support and state exposure. Do not hide critical content.

Related: `disclosure`.
