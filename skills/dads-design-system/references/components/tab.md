# Tab

Purpose: Switch between related panels in one region.

Use when multiple views share one content area.

Avoid when all content should remain visible at once.

Key rules:
- One active tab at a time.
- Each tab maps to one panel.
- Keep tab labels short and parallel.

Accessibility: Use tablist/tab semantics and arrow-key navigation.

Related: `disclosure`, `menu-list`. Status: Guidance is pending.
