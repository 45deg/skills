# Link Text

Links must be easy to identify and understand. Use color together with another cue such as underline, icon, or marker so the link remains recognizable when color is reduced or unavailable.

Behavior rules:
- Use link text that names the destination or action, not a vague prompt.
- Keep unvisited and visited states distinguishable when that difference helps users keep track of what they have already opened.
- Let hover and active feedback reinforce the control without causing layout shift or hiding the link affordance.
- Keep focus treatment visible and non-color-only.
- Signal new-tab links and non-web files consistently in the visible label, icon, or both.

Prefer specific, reusable phrases over generic labels like "here" or "read more". When generic text is unavoidable, make each instance distinguishable through surrounding text or accessible labeling.
