# Corner Shapes

Use corner shape as part of component identity and emphasis. A radius that works on one size may look too round or too sharp on another, so treat corner shape as a responsive design decision, not a fixed decoration.

Practical radius vocabulary:
- `0`: sharp.
- `8`: small rounding.
- `16`: medium rounding.
- `32`: large rounding.
- `50%`: pill or circular shape.

Rules:
- Tune radii by component size and aspect ratio so the same style reads consistently across cards, buttons, and other surfaces.
- Use roundness to clarify grouping, emphasis, or component family, not as decoration alone.
- Use full-corner rounding when the component role benefits from a pill or circular silhouette.
- Use partial rounding only when it reinforces component structure, such as a composite surface or attached control.
