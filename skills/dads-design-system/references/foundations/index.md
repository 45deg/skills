# Foundations

Foundations are the top-level design layer. Use them before choosing component details, because they define the default visual language the rest of the system should follow.

Read foundations as a system:
- `color.md` and `color-palette.md` define visual meaning and contrast-aware color selection.
- `typography.md` and `typography-text-style.md` define reading rhythm, density, and type tokens.
- `layout.md` and `spacing.md` define structure, alignment, hierarchy, and responsive behavior.
- `icon.md`, `link-text.md`, `elevation.md`, and `corner-shapes.md` define repeated interaction and surface cues.

Keep foundation decisions consistent across screens so the product feels like one system. Adapt them only when the product content, workflow, or environment clearly requires it, and keep those exceptions intentional.
