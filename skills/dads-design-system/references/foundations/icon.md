# Icon

Use icons to strengthen recognition, state, or navigation. Treat them as part of the meaning of a control or label, not as decoration by default.

Placement roles:
- Front icon: leads a block-level component and frames the start of a grouped surface.
- End icon: closes a block-level component and often signals outcome, affordance, or destination.
- Lead icon: begins an inline text run and should read as part of the same phrase.
- Tail icon: ends an inline text run and should feel attached to the same text sequence.

Match placement to the surrounding layout and reading order. Inline icons should behave like text; block-level icons should anchor the component they belong to. Do not mix placements casually within one pattern.

Prefer icons with visible labels. Use icon-only treatment only when the layout or control pattern genuinely needs it, and then defer to the accessibility rules for naming, target size, and contrast.
