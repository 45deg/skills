# Typography

- Support user-controlled font changes and text zoom without losing content or function.
- Avoid text rendered as images except where unavoidable, such as a logo.
- Keep italics rare, especially in Japanese text, and avoid long italic passages.
- Use readable line height and paragraph spacing so blocks remain scannable after enlargement.
- Keep line length moderate, but prioritize completeness when the content must be exhaustive.
- Use responsive layout so enlarged text reflows cleanly instead of clipping or overlapping.
- Preserve headings, labels, and body copy as real text so assistive tech can expose structure and meaning.
- Do not encode meaning only through weight, size, or style changes if the same meaning is not also present in text.
