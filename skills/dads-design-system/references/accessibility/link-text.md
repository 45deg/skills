# Link Text

Link text needs to make sense when it is isolated in a link list, read by a screen reader, or scanned quickly with the keyboard.

- Make link text describe the destination or action.
- Prefer unique, specific phrases over vague labels like "here" or "read more".
- Prefer page titles, headings, or clear noun phrases when possible.
- If repeated generic text is unavoidable, distinguish each instance with accessible labeling.
- Use visible link styling together with the text so the control is still recognizable without color alone.
- Aim for generous clickable areas; links should not be tiny touch targets. If the visible text is short, expand the hit area with padding or nearby spacing.
