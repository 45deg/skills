# Spacing

Spacing can create accessibility problems when it is used as a substitute for structure.

- Do not use letter spacing, word spacing, or justification to fake layout or alignment.
- Do not use repeated spaces or nonbreaking spaces to position content.
- Let layout come from semantic structure and CSS, not from text glyph tricks.
- Treat justified text with caution because uneven spacing can make text harder to follow.
- Be especially careful in labels, table cells, and other compact content where small spacing changes have a large effect.
- Prefer explicit containers, alignment rules, and spacing tokens over visual guessing with characters.
